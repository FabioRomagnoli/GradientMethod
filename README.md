# PACS_Grad_Method
Function minimizer. Utilizes the gradient method to mind the minimum of a multivariate function. The learning rate for the the utilized gradient method can be modified to achive better convergence. There are multiple choices for this learning rate. namely exponential decay, inverse decay, and the approximate line reach. The gradient needs for the computation of the minumum can be provided analitically or computed trough finite differences. 



The program has been designed so that the choice of the learning rate and gradient computation can be made at runtime. This is achived through a polymorphic design that employes a base class that has a virtual () operator, making the subsequent children classes that override the operator, function objects. The decision is made through a set of switch statement over an enum of possibilities. When a method is picked a unique pointer of the child class is created and casted to a unique pointer of the base class that is a member of the class that handles computation. Any subsequent call to the picked method is routed to the children class. All the parameters of the minimizer as well as the function and its gradient can be defined at runtime by modifying the param file. The parameters are read trough GetPot, and the functions are parsed and evaulated with muParserX. The expression is wrapped in a functionParser class (mostly taken but slightly modified from the PACS Example). All the vector algebra is handled by the Eigen library.
